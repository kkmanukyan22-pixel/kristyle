# Kristyle — сайт

Статический сайт без сборки: HTML + CSS + JS. Стиль «Плакат»: Bold Red #B81D23, Ink Black, Sandstone #D1C0A6; заголовки Unbounded Black, текст Montserrat.

```
index.html            главная: первый экран, услуги, кейсы, как проходит работа, обо мне, контакты
cases/clip.html       кейс: образы для клипа
cases/concert.html    кейс: два образа на концерт
cases/consultation.html  кейс: цветотип и стиль
css/style.css         все стили
js/main.js            анимации, меню, галерея, форма
assets/img/           сюда фото
favicon.svg
```

Локальный просмотр: `python3 -m http.server 8765 --directory kristyle` → http://localhost:8765

## Как вставить фото

Любой серый блок с подписью в квадратных скобках — это `<div class="ph">`. Вместо `<span>[…]</span>` внутрь вставить:

```html
<img src="assets/img/about.jpg" alt="Короткое описание образа" loading="lazy">
```

(на страницах кейсов путь `../assets/img/...`). Фото автоматически станет ч/б с растром, а там, где у блока класс `color-on-hover`, при наведении будет в цвете. Размер: по длинной стороне до 2000 px, JPG/WebP до ~400 КБ.
